# DESIGN.md — Nitin Kumar Patwa Portfolio Design System

## Overview
High-impact editorial portfolio design system featuring:
- Archivo heavy uppercase headlines with outline words
- Color block scheme: Paper (`#F1F1EE`), Paper-Warm (`#D9D9D4`), Ink (`#101010`), Lime (`#CBFF44`), Lavender (`#F5F2F8`)
- Monospaced labels & 1px hairline borders
- Underline-arrow link CTAs
- 0px border-radius
- Interactive SVG cursor spotlight wordmark
- Counter-rotating skill orbit
- Hairline-cell grids with interactive filtering and expandable project bullet details
- Underlined contact form fields with server-side handling and fallback
