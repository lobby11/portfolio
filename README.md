# Nitin Kumar Patwa — Personal Portfolio

Personal Developer Portfolio of **Nitin Kumar Patwa** (Full-Stack Web Developer).

## Tech Stack
- **Framework:** Next.js (App Router), React.js, TypeScript
- **Styling:** Tailwind CSS, Custom Editorial Design System (Archivo heavy headlines, hairline cell grids, paper/ink/lime/lavender theme blocks)
- **Animations:** GSAP, SVG Spotlight Cursor, Rotating Skill Orbit
- **Deployment:** Vercel / AWS

## Features
- Single source of truth at `src/data/portfolio.ts`
- Interactive project filter grid with smooth expansion for resume bullet points
- Rotating tech skill orbit & stat counters
- Server-side contact form route handler (`/api/contact`) with validation, rate limiting, and honeypot protection
- Full accessibility, performance optimizations, SEO metadata, JSON-LD Person schema, and sitemap
